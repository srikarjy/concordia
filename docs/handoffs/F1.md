## Changes

### Provenance integrity

`verification/cross.py` now validates a typed execution record for a
structure-scope claim. Eligible execution must be terminally successful and
must bind the claimed source-sequence digest, model checkpoint, and settings
digest. It must retain request and response artifacts and depend on the claimed
source. Malformed, failed, mismatched, missing, or unrelated execution records
make the affected evidence unverifiable.

The review reproducer from `docs/reviews/2026-10-20-t1-t3-review.md` is covered:
an unrelated failed operation attached as a sibling cannot yield `SUPPORTED` or
`scientific_use_allowed=true`. A list-valued execution payload is rejected as
malformed rather than raising `AttributeError`.

### Embedding-cache identity

`scripts/evaluate_tsuboyama_predictor.py` no longer reuses a Parquet cache by
variant IDs alone. Reuse now requires one of:

- the reviewed frozen asset manifest's exact cache SHA-256 plus the requested
  sequence/variant-position mapping; or
- a sidecar provenance record containing the cache digest, sequence digest,
  complete variant-position mapping, feature identity, checkpoint revision,
  and weight digests.

An unverified historical cache is never relabeled with today's ESM-2 revision;
the script requests fresh extraction and records new sidecar provenance instead.

### Asset accounting

`scripts/check_stability_assets.py` now reads the full frozen serving manifest,
including calibration, instead of maintaining a partial hard-coded list.
`scripts/package_stability_assets.py` verifies all bytes before producing a
local archive. The current local release artifact is:

```text
artifacts/concordia-stability-assets-v1.tar.gz
SHA-256: 16643a71a6d69d03c28539d21d076e3b40d46d12eedcd939e420c2fd97736b41
Size: 22 MB compressed
```

It contains the manifest plus the normalized table, 1IGV structure, embeddings,
ensemble, ranker, frozen calibration, and uncertainty artifact. It is gitignored
and has not been published. `docs/installation-and-checks.md` documents how to
build it and why public redistribution remains pending.

### Revision-correct replay exports

The static review replay now produces `r1-*` through `r7-*` exports. Selecting
revision 1 links to revision 1 CSV/HTML/ZIP, instead of silently downloading
the final revision's shortlist. Each ZIP verifies independently. Browser tests
assert the historical revision's selected export does not contain final-only
selection K6Q.
