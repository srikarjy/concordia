# F3 handoff — reviewer replay disclosure

Date: 2026-10-20. F3 is complete for the bounded static replay scope. It does
not claim a completed explanation viewer or a user-study result.

## Changed

The read-only 1IGV replay now displays a dedicated `Fresh model execution`
panel. It says that the score table contains historical recorded ranking inputs
and that the pinned, fresh ThermoMPNN S1A feasibility attempt is unavailable.
The panel links to the signed machine-readable record instead of presenting an
explanation overlay or implying a live model call.

`scripts/build_review_replay.py` validates the F2 JSON record against its
SHA-256 sidecar and packages it in `frontend/public/review-replay/`. Every
revision-specific export bundle also retains the record under `diagnostics/`
with a digest manifest verified by the bundle's standalone `verify.py`.

## Verified

```sh
PYTHONPATH=src .venv/bin/python scripts/build_review_replay.py
cd frontend
npm run check
npm run build
npm run build:stability
npm run test:all
```

All checks passed after rebuilding `frontend/dist`. Browser suites: 8 workspace,
3 local, and 7 public tests. The first local replay attempt served a stale
`dist` bundle after only `dist-stability` was rebuilt; rebuilding the standard
bundle resolved it. Build warnings remain for large Molstar chunks and a
third-party 3Dmol `eval` warning.

The five-minute script and built UI screenshot are in
`docs/portfolio-demo.md` and `docs/screenshots/variant-review-replay.png`.
Do not add an explanation overlay unless a future pinned model run passes the
mapping, parity, and gradient gates recorded in F2.
