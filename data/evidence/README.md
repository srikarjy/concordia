# Evidence sources

This directory will hold the small, frozen evidence corpus supplied to the scientist model. The source manifest records bibliographic provenance and intended use; it does not claim that any source has already been selected for the MVP packet.

Keep only short, rights-cleared excerpts in a future `payloads/` directory. Preserve the source URL, PMID/DOI, retrieval date, license or copyright status, excerpt boundaries, and SHA-256 checksum. Never retrieve documents during a condition run. The packet builder must embed the exact approved excerpts and their stable evidence identifiers.

The first source candidates below were identified through PubMed. They are background candidates about AhR biology, Tox21 screening, and the limits of structure-based toxicology interpretation. Their reported model results are not Concordia results and must not be copied into the project as baseline performance.
